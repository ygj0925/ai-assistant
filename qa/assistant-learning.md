# Web 学习模式验收

工作区的「学习模式」直接打开内置示例。用户可查看引导、图表和选择题，提交后查看得分及逐题解析。切换「文本练习」后，图表改为带标题和行列标签的表格，答案通过题号对应的数字输入提交。切换时保留已填答案。

「导入课程 JSON」接受最多 16 KiB 的结构化文本。内容在浏览器内解析和评分，关闭面板后清除会话内练习状态。课程中的标题、说明、选项和图表标签按普通文本呈现。

```json
{
  "title": "比较借阅量",
  "guide": ["找到较大的数值。"],
  "questions": [
    {
      "prompt": "哪一天借阅得更多？",
      "options": ["周一", "周二"],
      "answer": 2,
      "explanation": "7 大于 4。"
    }
  ],
  "chart": {
    "title": "借阅量",
    "unit": "本",
    "points": [{"label": "周一", "value": 4}, {"label": "周二", "value": 7}]
  }
}
```

`answer` 从 1 编号。每份课程需要 1–6 条引导、1–10 道题，每题可设 2–6 个不同选项。可选图表支持 1–12 个数值及正负数。导入无效数据时保留当前课程。

在 `clients/web` 运行 `npm run typecheck` 与 `npm test -- tests/learning.spec.ts`。浏览器用例覆盖键盘作答、断网、缺少答案时定位到题目、文本版提交与解析、课程导入校验、字面展示标记文本和窄屏布局。

2026-11-24，Windows Chrome 对生产构建的两项 Playwright 用例通过。断网后从结构化图表选取两个项目并计算差值，切换文本表格后保留结果。交互版和文本版使用同一答案与解析，320 像素宽度验证无横向滚动。

同日，Android API 36 的 Google Pixel Tablet 调试环境在 Wi-Fi、移动数据及 API 转发都关闭后，从历史打开同一练习。文本图表正确列出 4、7、6。漏答时聚焦第一题，输入两个答案后得到 2/2 和两条解析，使用系统返回键及页面按钮均回到历史。移动端与 Web 共用课程格式和评分，TypeScript 检查、共享评分快照和两端 Hermes 导出通过。 [Android 证据](../clients/mobile/.expo/learning-2026-11-24/android-results.json)

当前课程使用内置内容或用户导入的 JSON，答案只保存在面板打开期间。已验证的原生交互环境是 Android API 36，iOS Hermes 导出已通过。
