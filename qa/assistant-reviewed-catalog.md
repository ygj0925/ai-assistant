# 经审核的助手与连接器目录

目录面向已登录用户展示经过独立审核的助手版本及第一方本地模拟连接器说明。作者选择当前自己拥有的确切助手版本，先审阅标题、正文说明和摘要，再确认提交。说明正文按公开展示处理。包含项目资料或工具的私有助手版本无法提交。

- 用户提交和发现入口由 `assistant.catalog.enabled` 控制。ContiNew 审核由独立的 `assistant.catalog.review-enabled` 控制，两项默认关闭。
- 平台审核人须持当前有效的 ContiNew 会话、`assistant:catalog:review` 或 `assistant:catalog:publish` 权限，以及精确的租户、平台账号和作者工作区分配。决定操作额外检查该分配的 `can_decide`。平台权限与消费账号分别验证。
- 审批绑定不可变的候选版本与作者确认的内容摘要。批准后，条目地址保留，版本更新用当前已发布版本做并发校验。恢复旧版本需要重新审阅和批准。作者撤回、审批拒绝、更换版本与运营紧急撤回均使对应的旧发布记录失效。
- 浏览列表不含助手说明正文，详情只展示经明确同意并审核发布的字段。目录响应不含作者账户、私有工作区、源项目资料或内部版本标识。举报绑定当前可见的确切发布版本，单人单版本只存一条。
- 第一方连接器仅提供 `fixture_notice` 功能说明。一个配置好的 `assistant.catalog.connector-author-workspace` 允许其组织所有者提交全局唯一条目。目录项没有安装、授权或执行入口。
- 独立撤销日志在数据库恢复时阻止旧发布重新出现。删除底层定制助手、清除账户或撤销作者的确切工作区成员关系时，删除相应目录数据。发现与详情继续复核源版本和当前成员关系。

本地自测使用两个签入用户、隔离 ContiNew 审核账号和独立的项目数据。 `qa/assistant-reviewed-catalog-smoke.mjs` 验证确切公开正文、过期候选拒绝、经审核回滚、举报去重、紧急撤回、源数据删除及备份恢复。平台会话由测试器从合成实例获取，只保留在进程内。生产第三方插件接入、市场分发及其合同和供应商账户属于后续上线依赖。

- PostgreSQL 16 新库从零应用 163 项 Liquibase 变更。用仍能查看已发布条目的旧备份和相同撤销日志恢复后，重启应用零项迁移。HTTP 确认助手和连接器旧发布撤回、举报去重、明确重审更新和回滚、材料引用保持私有、私有源删除，以及成员退出和重新加入后的旧版本保持不可见。
- 同一恢复库关闭目录和审核开关后，用户发现和提交入口返回 403。作者可以查阅自己已有的状态，具备确切授权的运营人员仍可紧急撤回。[HTTP、恢复和开关验证](verify-results/reviewed-catalog-2026-11-24/replay.log)
- 实际 ContiNew 普通角色已分配确切测试工作区的审核范围，但无所需平台权限，读取审核详情和批准均返回 403。[权限验证](verify-results/reviewed-catalog-2026-11-24/rbac.log)
- 生产 Web 构建用 Chrome 验证作者逐字预览、确认前无提交、待审条目不可发现、真实运营批准、已登录用户查看及举报、作者撤回和私有原件保留。[浏览器验证](verify-results/reviewed-catalog-2026-11-24/browser-fixed.log)
- MySQL 8.4 隔离命名管道应用五项目录迁移。核验已审核版本、审核日志、举报和 `CAT_REV` 支持，源记录删除级联，跨工作区 FK 和无审核时间发布均被拒绝，既有检索目录三条保持不变。[原生迁移验证](verify-results/reviewed-catalog-2026-11-24/mysql.log)
