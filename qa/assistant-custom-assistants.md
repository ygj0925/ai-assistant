# 私有定制助手验收

当前工作空间的所有者可以保存定制助手，指定名称、指令和选填的私有项目。名称限制为 120 个 Unicode 码点，指令限制为 2000 个。项目固定后，每个版本可有最多 8 个不同的自有文本资料。版本保存资料标识，使用时重新核验项目、资源和账号权限。

每次修改须提交当前版本标识。成功修改产生新的不可变版本。回退会重新校验所选历史版本的资料和工具配置，再创建一个新版本并在其中记录回退来源。历史配置保留所有者原先提交的文字和资料标识。删除助手后，版本及资料关联一并删除。

初始工具只允许 `project_resource_lookup`，并要求已选至少一条当前项目资料。已启用的测试环境中，用户可在模型为 `local-echo` 且项目完全匹配的对话里选择当前版本。运行记录版本标识，加载指令以及工具允许的首个匹配文本片段。私有输入和回复先在本地缓冲，发布前锁定并再次校验账号、成员、会话项目、版本与资料授权。 [项目文本资料](assistant-project-resources.md)

## 复跑

在独立回环后端中开启 `ASSISTANT_CUSTOM_ASSISTANTS_ENABLED=true`，启用测试注册、项目文本资料和已绑定的独立删除日志。每个账号可保留 16 个定制助手，每项有 20 个不可变版本。 [独立日志](assistant-erasure.md)

```powershell
node qa/assistant-custom-assistants-smoke.mjs http://127.0.0.1:18120
```

脚本验证工作空间和项目隔离、允许的工具、创建重试、并发修改保护、生成新版本、回退、已撤销资料、注销与级联清理。

在同一隔离环境使用 `assistant.models.mock-enabled=true` 和 `assistant.models.mock-delay-millis=70`，运行 `node qa/assistant-custom-runs-smoke.mjs http://127.0.0.1:18120`。脚本核对运行绑定、项目隔离、工具显式启用、版本冲突、用量以及生成期间撤销资料。

备份恢复测试使用空证据目录。脚本发布 `backup-ready.json` 后备份原库，再创建 `backup-done`。脚本修改一项助手，创建后撤销另一项，再发布 `deletion-ready.json`。停止原库对应的测试服务，将备份恢复至另一测试库，使用同一日志启动恢复端，然后创建 `restore-done`。

```powershell
node qa/assistant-custom-assistants-smoke.mjs http://127.0.0.1:18120 --replay $evidence http://127.0.0.1:18121
```

恢复测试检查旧版本显示为待复核，用户仍可主动创建新的生效版本。已撤销的助手即使创建于备份之后，原请求标识也不能重新创建它。

同日，完整后端在隔离 PostgreSQL 和 Redis 完成接口验收。三个不可变版本顺序正确，回退后的标识和历史版本不同，旧版本并发写入被拒绝。另一账号和另一项目无法访问该配置或加入错误资料，撤回资料后无法激活引用它的旧版本。删除助手后原请求标识无法重新创建，注销含实际资料关联的账号后旧会话失效。
