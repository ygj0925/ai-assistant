# 私有项目 CSV 数值分析验收

在已授权的项目文本资料内选择一个数值列。服务使用 `csv_numeric_v1` 计算最小值、最大值、总和与均值，并保存结果标识、源资料、所选列、耗时和算法版本。数值结果以十进制字符串返回。均值最多保留 12 位小数，使用半数进位。摘要携带前 32 个数值供图表显示，并记录忽略的空值数及图表是否截断。CSV 产物包含全部有效数值的原始行号。

输入复用项目文本资料的 16 KiB 限制。解析支持引号、转义双引号和带引号单元格内换行。表格最多 32 列和 256 个数据行。所选列的空单元格不参与计算，其他选定值需要符合十进制语法。无有效数值、重复标题、列宽不一致、错误引号和公式都被拒绝。

产物使用固定列头和经过解析的数值，文件名为 `analysis.csv`。读取摘要、下载产物和重复提交时都要重新检查源资料权限。源资料删除后，分析结果和产物一并撤回。

## 运行

使用独立 PostgreSQL 和 Redis 启动回环测试服务，启用注册。分析开关为 `--assistant.analysis.enabled=true`，还需启用[项目文本资料和独立删除日志](assistant-project-resources.md)。脚本仅向显式回环测试端口发请求并创建合成数据。

```powershell
node qa/assistant-csv-analysis-smoke.mjs http://127.0.0.1:18103 normal
node qa/assistant-csv-analysis-smoke.mjs http://127.0.0.1:18104 disabled
```

正常用例核对精确聚合、重复请求、CSV 下载字节、表格列数和行数上限、异常输入、跨账号和项目拒绝、源资料删除后的状态。测试在未分析列中放入指向脚本自建回环服务的链接，检查回环服务请求数与分析前后的模型用量。回环探针与账本比较各验证一个实际观察结果，任意其他形式的外部流量需要隔离环境的独立证据。

## 备份恢复联测

`restore` 使用与[私有项目资料验收](assistant-project-resources.md#备份恢复联测)相同的备份和数据库切换标记。`backup-ready.json` 另外提供 `removedAnalysisId` 与 `retainedAnalysisId`。恢复源资料删除前的备份，并使用最新独立删除日志启动服务后，脚本确认原资料的分析摘要与产物仍不可访问。对照资料的摘要、CSV 字节和重复提交的结果标识应保持一致。

```powershell
node qa/assistant-csv-analysis-smoke.mjs http://127.0.0.1:18103 restore qa/verify-results/csv-analysis-restore
```
