# 定时提醒验收

提醒由当前工作空间的创建人管理。支持一次、每天或每周同一日的站内提醒，时间按创建时选择的 IANA 时区解释。设置的静默时段包含开始时刻，结束时可投递，也可跨午夜。每个账号可保留 32 项提醒，每项提醒可查看最近 90 条运行记录。

春季跳时中的提醒向后顺延实际跳过的长度。秋季重叠中的同一提醒使用较早的时刻，一个日历时段只生成一条通知。静默边界落在重叠时段时，选较早的开始和较晚的结束。边界落在跳过时段时，使用首个有效时刻。 [Java 时区规则](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/time/zone/ZoneRules.html)

Worker 恢复后只补最近一条应投递而且晚到不超过 24 小时的记录。恢复时正在静默则延迟到结束。超出补偿窗口的一次性提醒记为已过期。暂停保留既有记录并停止新通知，显式恢复后从未来日历时段开始。删除清理提醒及其运行记录。

## 复跑

启动独立回环服务、PostgreSQL、Redis 和消费者注册。打开 `ASSISTANT_REMINDERS_ENABLED=true`，使用已绑定、可写的独立删除日志。站内提醒与运行记录可在所有者的当前工作空间查看。 [独立日志](assistant-erasure.md)

```powershell
node qa/assistant-reminders-smoke.mjs http://127.0.0.1:18117
```

脚本等待一个真实的整分触发，验证重复提交、工作区和账号隔离、站内通知、重复 Worker 轮询、标为已读、暂停恢复、取消和注销。固定时钟单元用例覆盖跳时、重叠、半小时跳时、跨午夜静默、长时间停机补偿及恢复时仍处于静默。

使用已有空目录协调 PostgreSQL 备份恢复。启动下面的脚本后，等 `backup-ready.json` 写入，再备份原测试数据库并创建 `backup-done`。脚本暂停及取消样例，写入 `deletion-ready.json`。停止原服务，恢复独立数据库，并用原绑定日志启动另一个回环服务，成功后写入 `restore-done`。

```powershell
node qa/assistant-reminders-smoke.mjs http://127.0.0.1:18117 --replay $evidence http://127.0.0.1:18118
```

脚本验证暂停和取消在旧备份恢复后仍生效，取消的请求标识无法重建提醒，保留的提醒可显式恢复。测试范围为本地日历计划和站内通知。连接器事件、设备推送和后续计划分享仍按各自的任务验收。
