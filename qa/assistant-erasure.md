# 账号注销与恢复后删除重放

启用助手后端的可恢复删除时，配置已有的独立日志和日志标识。日志需保存在数据库备份恢复范围以外，仅由一个助手进程持有写锁。新部署预先创建日志，并使用 UTF-8、LF 结尾写入首行 `assistant-deletion-journal-v1 <UUID>`。恢复既有部署时复用原文件与 UUID。

```text
--assistant.privacy.erasure-enabled=true
--assistant.privacy.journal-path=<独立日志的绝对路径>
--assistant.privacy.journal-id=<首行的 UUID>
```

客户端以消费者令牌提交 `POST /api/assistant/v1/privacy/account-erasure`，请求含当前密码 `currentPassword` 和固定确认值 `confirmation`，确认值为 `DELETE`。应用校验当前令牌、账户与密码，在独立日志写入并同步删除意图。随后在数据库事务中撤销全部设备会话与成员资格，取消尚未结束的运行并结算已交付用量，清除资料和私有内容。事务提交后返回 204。

日志仅持久化删除类型、对象标识、归属、时间以及校验链。已删除账户以不可登录的内部标识保存账本与订单引用。对话、消息与运行记录的正文会清空，结算与运营审计保留其引用和必要字段。账号注销后，现有设备和重新登录均无法访问账户及其导出。

启用同一日志后，常规会话删除也记录独立意图，完成在线撤权与正文清除。默认关闭此功能的部署沿用原有会话软删除，账号注销入口返回 403。数据库在首次启用时绑定日志 UUID，此后禁用开关或更换另一份日志都会阻止启动，包括绑定后尚未发生删除的备份。日志打不开、无法独占、校验失败或恢复记录缺失也会阻止启用的部署开放服务。

## 恢复步骤

1. 保持用于恢复的应用入口关闭，恢复数据库备份与其迁移记录。
2. 以原配置启动，确保独立日志包含备份之后的删除意图。助手在提供用户请求和派发模型任务前验证绑定与日志并重放。首次启用以前的备份由独立恢复运行手册显式附加原日志和标识。
3. 核对 `assistant_deletion_applied`。已应用的删除在再次启动时跳过，未提交的主库事务通过同一日志重试。确认旧设备、历史、搜索与导出继续拒绝已删除对象。

在当前单写入者实现中，独立日志上限为 16 MiB。日志需覆盖仍可恢复的最早快照及其后的删除事件。部署进程持有排他锁，备份只读日志或复制时应由运维确保来源完整。多实例部署、外部附件与供应商副本，以及生产备份到期与异地恢复仍依赖相应的发布环境验证。

## 本地自测

助手模块的定向 JUnit 测试覆盖关闭开关、独占锁、断裂记录、校验异常、待应用阻断及重开日志。 [回环自测模块](assistant-erasure-smoke.mjs)提供三个保持合成凭据在同一进程内的步骤。先运行 `prepareErasureFixture` 创建模拟账号、设备和会话并启动活动运行，随后备份该模拟数据库。运行 `eraseFixture` 执行并验证删除。恢复删除前备份并挂载原日志后，再运行 `verifyErasure`。测试全过程使用模拟账号和回环后端。

隔离 PostgreSQL 的备份恢复实验通过。原库完成会话及账号删除后，使用删除前的真实备份恢复到另一库。当时备份内尚无删除记录，关闭功能或传入格式合法但 UUID 不同的独立日志均无法启动。复用绑定日志后，旧设备和重新登录被拒绝，已删除数据未重新出现在搜索、历史或导出。数据库核对两条应用记录及用量账本，确认活动运行结算、预留释放和敏感正文清除。重复启动保留相同应用记录，日志缺失会中止启动。测试完成后删除专用的两个数据库、临时数据库角色和快照。

使用完整 Maven 构建产物复测双账号与双设备。访客的 `account-erasure` 返回 `SIGN_IN_REQUIRED`，两个已登录账号均可用。错误当前密码返回 401 和 `INVALID_CURRENT_PASSWORD`，该会话仍可获取本人资料。替换为另一个工作空间的请求头时，资料、导出和 SSE 均返回 403。两个账号只读取自己的合成模型结果。

注销前，第二个设备从第一个设备实际读取的 SSE 游标续传，得到完全相同的剩余帧。注销后、从删除前备份恢复后及再次启动后，两台设备用原游标订阅都返回 401。另一账号继续读取自己的资料和保留的模型回复。测试通过回环 HTTP 和独立数据库完成。 [账号隔离自测](assistant-account.md) · [运行与续流自测](assistant-run.md)

MySQL 8.4.11 的独立迁移自测通过，验证了日志绑定表可保存唯一的合法位置，以及数据库会拒绝第二个位置。
